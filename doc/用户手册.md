## 1. 产品简介

### 1.1 什么是问渠

问渠是一款基于苏格拉底式对话的教材学习引擎，通过 AI 教师引导用户主动思考、加深理解，而非被动接受知识灌输。

### 1.2 核心特色

- 🎓 **8种教师角色**：各具风格的 AI 教师任你选择
- 📚 **三种学习模式**：速读、细读、研读，适应不同学习需求
- 🧠 **掌握项追踪**：清晰掌握学习进度，确保不遗漏知识点
- 🔄 **课后闭环**：自动生成学习日记、复习总结、教师点评
- 🎯 **结业答辩**：检验学习成果，颁发结业证书

## 2. 快速开始

### 2.1 创建课程

1. 点击侧边栏「➕ 新建课程」
2. 选择导入方式：
   - **上传文件**：支持 EPUB、MD、TXT 格式
   - **URL 抓取**：输入网页链接自动提取内容
   - **粘贴文本**：直接粘贴教材内容
3. 为课程命名
4. 点击「创建课程」

### 2.2 开始学习

1. 从课程列表选择要学习的课程
2. 系统自动分章并生成掌握项
3. 选择学习模式和教师角色
4. 点击「开始学习」进入对话

### 2.3 对话流程

```
📚 翻开教材 → 💭 分享观点 → ❓ 提出问题
       ↓                        ↓
   ✅ 掌握确认  ←  💬 你的回答  →  🔄 继续深入
```

## 3. 三种学习模式

### 3.1 🚀 速读·精华（15分钟）

**适用场景**：快速了解全书、建立知识地图

**核心特点**：
- 系统自动提取每章关键词和核心观点
- 提炼全书最重要的 5-10 个跨章知识点
- 推荐优先学习的章节顺序
- 每章仅需 1-2 轮对话

**学习流程**：
1. 展示本章知识快照（关键词 + 核心观点）
2. 提出 1 个关键概念理解题
3. 确认后进入下一章

**预期产出**：📊 知识快照 + 核心观点列表

---

### 3.2 📖 细读（30分钟）

**适用场景**：系统学习、全面掌握

**核心特点**：
- 均匀采样全书内容，不遗漏任何章节
- 每章生成 1-3 条掌握项清单
- 掌握项绑定对话，精准练习
- 实时追踪知识点覆盖度

**学习流程**：
1. 展示教材片段
2. 针对掌握项提出练习题
3. 根据回答自动标记掌握状态
4. 未掌握项进入下一轮练习

**预期产出**：📋 知识点掌握报告 + 复习总结

---

### 3.3 🔬 研读·辩证（60分钟）

**适用场景**：深度理解、批判性思考

**核心特点**：
- 全文深度学习，不截断内容
- 跨章节对比分析
- 隐含前提揭示与质疑
- 反方辩论触发机制
- 自动生成思辨笔记

**学习流程**：
1. 系统注入辩证分析指令
2. 每次提问引用前序章节对比
3. 连续认同触发反方辩论
4. 学习结束后生成思辨笔记

**预期产出**：🧠 思辨笔记 + 读书笔记

## 5. 学习契约

### 5.1 模式选择

根据学习目标选择模式：

| 模式 | 学习时长 | 认知深度 | 推荐场景 |
|------|----------|----------|----------|
| 🚀 速读·精华 | 15分钟 | 基础 | 快速浏览、建立认知 |
| 📖 细读 | 30分钟 | 标准 | 系统学习、全面掌握 |
| 🔬 研读·辩证 | 60分钟 | 深入 | 深度理解、批判思考 |

### 5.2 认知深度

| 深度 | 复述限制 | 提问复杂度 |
|------|----------|------------|
| 基础 | 80字以内 | 仅概念定义 |
| 标准 | 150字以内 | 角色默认风格 |
| 深入 | 不限 | 跨章对比、指出矛盾 |

### 5.3 学习时长

| 时长 | 最小轮次 | 可学章节 |
|------|----------|----------|
| 15分钟 | 3轮 | 1章或2个知识点 |
| 30分钟 | 6轮 | 1章完整学习 |
| 60分钟 | 12轮 | 2章或全部掌握项 |
| 120分钟 | 24轮 | 无限制 |

### 5.4 教师角色

| 角色 | 风格 | 特点 | 推荐场景 |
|------|------|------|----------|
| 🌸 三月七 | 活泼鼓励 | 元气少女、爱碎碎念 | 创意发散、初学入门 |
| ⚡ 刻晴 | 严格高效 | 外冷内热、追求卓越 | 技能训练、应试备考 |
| 🌿 甘雨 | 温柔引导 | 博学多识、耐心细致 | 知识探究、深度理解 |
| 🏛️ 苏格拉底 | 苏格拉底式 | 睿智谦逊、善于反问 | 哲学、理论思辨 |
| 🔧 林墨 | 问题驱动 | 直率务实、厌恶空谈 | 编程、工程实践 |
| 🌈 云逸 | 联想式 | 好奇跳脱、知识面广 | 创意写作、跨学科 |
| 🎯 知微 | 靶向式 | 敏锐务实、结果导向 | 考研、考证 |
| ☁️ 云岫 | 留白式 | 沉静深邃、惜字如金 | 文学名著、哲学原典 |

### 5.5 风格调控

拖动滑块微调教师风格：

```
严谨 ⇄ 发散    [-5 ──── 0 ──── +5]
鼓励 ⇄ 严厉    [-5 ──── 0 ──── +5]
简练 ⇄ 详实    [-5 ──── 0 ──── +5]
```

## 6. 课后产出物

学习结束后，系统自动生成：

### 6.1 学习日记

- 第一人称回顾学习经历
- 包含学习感悟和教师评价
- 100-200字，自然流畅

### 6.2 复习总结

结构化 Markdown 格式：

```markdown
## 📖 第X章 复习总结

### 🎯 核心知识点
- ...

### 💡 关键概念
- ...

### ❌ 易错提醒
- ...

### 📝 重点回顾
- ...
```

### 6.3 教师点评

群聊模式，其他 3 位教师从不同角度点评：

| 角色 | 点评角度 |
|------|----------|
| 三月七 | 生活化比喻 |
| 刻晴 | 指出逻辑漏洞 |
| 甘雨 | 补充背景知识 |
| 苏格拉底 | 提出反问 |
| 林墨 | 实际应用建议 |
| 云逸 | 跨领域联想 |
| 知微 | 考点提醒 |
| 云岫 | 精辟总结 |

### 6.4 学习画像

系统分析强项、弱项、误解，持续优化提问策略。

## 7. 结业答辩

### 7.1 答辩资格

- 知识点掌握率达到 100%
- 全部掌握项标记为「已掌握」

### 7.2 答辩流程

1. **开始答辩**：点击「申请结业答辩」
2. **答题环节**：限时 10 分钟回答 3 道开放式问题
3. **评估结果**：系统逐题评判 PASS/FAIL
4. **颁发证书**：全部通过获得结业证书

### 7.3 证书内容

- 课程名称
- 授课教师
- 学习时长
- 强项总结
- 教师寄语

## 8. 高级功能

### 8.1 划词问答

在学习过程中，选中任意文本可随时追问：

1. 长按选中文本
2. 点击浮动「💬 追问」按钮
3. 输入问题并发送
4. AI 给出精准解答

### 8.2 苏格拉底式预演

学习当前章节时，预览下一章的引导问题，带着问题学习效率更高。

### 8.3 快速标记已掌握

点击「⏭️ 我已掌握」按钮，系统自动标记该知识点并进入下一题。

### 8.4 模式联动

选择学习模式后，系统自动推荐：

| 模式 | 默认深度 | 默认时长 |
|------|----------|----------|
| 速读·精华 | 基础 | 15分钟 |
| 细读 | 标准 | 30分钟 |
| 研读·辩证 | 深入 | 60分钟 |

## 9. 常见问题

### Q1: 支持哪些文件格式？

支持 EPUB、Markdown (.md)、纯文本 (.txt)。PDF 暂不支持，建议使用 EPUB 格式。

### Q2: 学习中途可以暂停吗？

可以。关闭页面后，系统会保存对话记录，下次打开可继续或查看历史。

### Q3: 如何删除课程？

在课程详情页点击「删除课程」按钮，确认后删除。

### Q4: 如何更改教师角色？

在学习契约区域重新选择教师，修改后不影响已学习的章节。

### Q5: 速读模式生成快照需要多长时间？

每章约 2-3 秒，全书快照 + 全局精华约 30 秒（取决于章节数量）。

### Q6: 思辨笔记是什么？

研读模式下，系统分析对话中的矛盾点、未解问题、延伸方向，生成结构化思辨笔记。

### Q7: 模型配置在哪里？

点击「🔧 模型配置」按钮，可添加多个 API 提供商和模型。
