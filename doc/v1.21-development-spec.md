-- 60 天后单独清理 PR

### 3.2 迁移策略（db-migrator playbook §迁移原则）

- **不要 DROP**：旧 `role_sliders` 表保留（不破坏 audit 数据，与 `spiritual_notes` / `chapter_snapshots` 等保留策略一致）
- **幂等**：迁移脚本可重跑（`INSERT OR IGNORE` + `WHERE NOT EXISTS`）
- **同 LLM 输出**：用户**首次访问新路径**时如有旧数据，按 `course_id → user_id` 的 1:1 聚合写入 `user_role_sliders`：
  - 同一角色多个课程设置 → 取**最后一次修改的**（按 `last_modified` desc，依赖 schema 加字段——见 3.3）

### 3.3 顺手加的字段（schema 变更）

```sql
-- role_sliders 表加 last_modified 字段（迁移用），保留旧数据
ALTER TABLE role_sliders ADD COLUMN last_modified TIMESTAMP DEFAULT CURRENT_TIMESTAMP;

-- 新表索引用 IF NOT EXISTS 模式，保证幂等
CREATE INDEX IF NOT EXISTS idx_user_role_sliders_user
    ON user_role_sliders(user_id);
```

### 3.4 在 `_migrate_schema()` 中的位置

`database.py` 已经定义 `_migrate_schema()` 函数。**新增逻辑追加到末尾**，不影响已有迁移：

```python
def _migrate_schema():
    conn = get_conn()
    try:
        # ... 现有迁移逻辑保持原样 ...

        # ---------- v1.21 切片 B 迁移 ----------
        # 1) 给老 role_sliders 加 last_modified
        cols = {row["name"] for row in
                conn.execute("PRAGMA table_info(role_sliders)").fetchall()}
        if "last_modified" not in cols:
            conn.execute(
                "ALTER TABLE role_sliders ADD COLUMN last_modified TIMESTAMP DEFAULT CURRENT_TIMESTAMP"
            )

        # 2) 新表（幂等）
        conn.execute("""
            CREATE TABLE IF NOT EXISTS user_role_sliders (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                user_id TEXT NOT NULL,
                teacher_role_id TEXT NOT NULL,
                strictness INTEGER DEFAULT 0,
                encouragement INTEGER DEFAULT 0,
                verbosity INTEGER DEFAULT 0,
                source_course_id TEXT,
                last_modified TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
                UNIQUE(user_id, teacher_role_id)
            )
        """)

        conn.execute("""
            CREATE INDEX IF NOT EXISTS idx_user_role_sliders_user
                ON user_role_sliders(user_id)
        """)

        conn.commit()
    finally:
        conn.close()
```

> db-migrator checklist：✅ `CREATE TABLE IF NOT EXISTS` / ✅ 不 DROP 旧表 / ✅ 幂等可重跑 / ✅ 加索引。

### 4.3 `database.py` 新增函数

```python
def get_user_sliders(user_id: str, teacher_role_id: str) -> dict:
    """v1.21: 用户级滑块查询"""
    conn = get_conn()
    try:
        row = conn.execute(
            "SELECT strictness, encouragement, verbosity "
            "FROM user_role_sliders WHERE user_id=? AND teacher_role_id=?",
            (user_id, teacher_role_id)
        ).fetchone()
        if row:
            return {
                "strictness": row["strictness"],
                "encouragement": row["encouragement"],
                "verbosity": row["verbosity"],
            }
        # 无记录 → 返回角色默认值
        from config import DEFAULT_SLIDERS
        return DEFAULT_SLIDERS.get(
            teacher_role_id,
            {"strictness": 0, "encouragement": 0, "verbosity": 0}
        )
    finally:
        conn.close()


def save_user_sliders(user_id: str, teacher_role_id: str,
                     strictness: int, encouragement: int, verbosity: int,
                     source_course_id: Optional[str] = None):
    """v1.21: 用户级滑块保存（upsert）"""
    conn = get_conn()
    try:
        conn.execute("""
            INSERT INTO user_role_sliders
                (user_id, teacher_role_id, strictness, encouragement,
                 verbosity, source_course_id, last_modified)
            VALUES (?, ?, ?, ?, ?, ?, CURRENT_TIMESTAMP)
            ON CONFLICT(user_id, teacher_role_id) DO UPDATE SET
                strictness=excluded.strictness,
                encouragement=excluded.encouragement,
                verbosity=excluded.verbosity,
                source_course_id=COALESCE(excluded.source_course_id, source_course_id),
                last_modified=CURRENT_TIMESTAMP
        """, (user_id, teacher_role_id, strictness, encouragement, verbosity,
              source_course_id))
        conn.commit()
    finally:
        conn.close()
```

### 5.3 章节列表 3 块结构（切片 A）

**现状**（`static/js/app.js:1203-1256`）渲染 6-8 块。

**目标态函数签名**：

```javascript
/**
 * v1.21 切片 A: 章节项渲染收敛到 3 块
 * @param {Object} ch - chapter
 * @param {Array} chapterSyllabus - 该章掌握项
 * @param {boolean} isSpeedMode
 * @returns {string} innerHTML 片段
 */
function renderChapterItem(ch, chapterSyllabus, isSpeedMode) {
    const sessionCount = chapterSessionCounts[ch.idx] || 0;
    const mastered = chapterSyllabus.filter(s => s.status === 'mastered').length;
    const total = chapterSyllabus.length;

    // 派生信号
    const suggestedAction = computeSuggestedAction(ch, mastered, total, sessionCount);
    const primaryTag = pickPrimaryTag(ch, total);

    // 单 tag（多个同选最高优先）
    const tagHtml = primaryTag ? `<span class="tag">${primaryTag.icon} ${primaryTag.label}</span>` : '';

    // 学习目标 / 核心观点：留更长的
    const summary = (ch.core_viewpoint?.length || 0) >= (ch.learning_goal?.length || 0)
        ? ch.core_viewpoint
        : ch.learning_goal;

    // 行为：状态驱动
    const actionText = suggestedAction === 'complete' ? '✅ 已掌握' :
                       suggestedAction === 'revisit' ? '🔁 再看一遍' :
                       suggestedAction === 'focus'    ? '🎯 重点精读' :
                       /* quick */                    '👀 快速浏览';

    return `
        <div class="chapter-item">
            <div class="chapter-index">📖</div>
            <div class="chapter-info">
                <div class="chapter-title-row">
                    <span>${ch.title}</span>
                    ${tagHtml}
                    <span class="badge">${total} 知识点 · ${mastered} 已掌握</span>
                </div>
                ${summary ? `<div class="chapter-summary">${summary}</div>` : ''}
            </div>
            <div class="chapter-actions">
                <button class="btn btn-outline btn-sm" onclick="startChat(${ch.idx})">
                    ${actionText}
                </button>
            </div>
        </div>
    `;
}

/**
 * 派生建议行为：避免重复 "建议性" 信息
 * - complete: 掌握度 ≥ 80% → 跳过
 * - focus: 核心章节 + 掌握度 < 80% → 精读
 * - revisit: sessionCount > 0 + 掌握度 < 50% → 重学
 * - quick: 默认
 */
function computeSuggestedAction(ch, mastered, total, sessionCount) {
    if (total === 0) return 'quick';
    const percent = mastered / total;
    if (percent >= 0.8) return 'complete';
    if (sessionCount > 0 && percent < 0.5) return 'revisit';
    if (ch.is_core || ch.importance >= 4) return 'focus';
    return 'quick';
}

/**
 * 单 tag 选择：核心 > 重要 > 精华，选一条
 */
function pickPrimaryTag(ch, syllabusCount) {
    if (ch.is_core) return { icon: '⭐', label: '核心' };
    if (ch.importance && ch.importance >= 0.7) return { icon: '🔥', label: '重要' };
    if (syllabusCount > 0) return { icon: '📋', label: '精华' };
    return null;
}
```
