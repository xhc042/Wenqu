## 🔧 覆盖率报告使用

### 查看 HTML 报告
```bash
# 打开覆盖率 HTML 报告
start htmlcov/index.html
```

### 生成覆盖率报告
```bash
# 生成终端报告
pytest tests/ -v --cov=. --cov-report=term-missing

# 生成 HTML 报告
pytest tests/ --cov=. --cov-report=html

# 跳过慢测试快速检查
pytest tests/ -v --cov=. -m "not slow"
```

## 📝 说明

- **测试代码覆盖率**: 指 `tests/` 目录下的测试文件自身覆盖率
- **生产代码覆盖率**: 指所有非测试文件的覆盖率
- **目标覆盖率**: 参考 `.harness/docs/architecture.md` 中的测试策略
- **慢测试**: 标记 `@pytest.mark.slow` 的测试,默认跳过
